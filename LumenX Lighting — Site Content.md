## **Design notes**

### **What the current design does well:**

* Technical expertise  
* Innovation  
* Precision  
* Premium positioning

* A clear B2B focus

### 

### **What needs to change**

The homepage is currently too long, too dark and too dependent on cards. Most sections have the same visual weight, so important information does not stand out from supporting detail. This makes the site harder to scan and weakens the buyer journey.

The design should create clearer separation between sections using:

* Alternating dark tones  
* Occasional lighter or technical-grey sections  
* Full-width project imagery  
* Technical drawings and simulations  
* Thin colour bands  
* More blank space  
* Different layouts from one section to the next

The website can remain predominantly dark, but it should not feel visually flat.

### **Reduce the number of cards**

Cards are currently used for almost everything: services, sectors, benefits, compliance and contact information. When every section is presented in the same format, nothing feels prioritised.

Use cards only where the content needs to be compared. Other sections should use:

* Horizontal process diagrams  
* Numbered steps  
* Full-width project features  
* Image-and-copy layouts  
* Partner-logo strips  
* Technical proof  
* Simple text columns

### **Improve readability**

The body copy is currently too muted and easy to skip.

Increase:

* Text contrast  
* Font size  
* Line spacing  
* Space between headings and explanations  
* Padding within content areas

The hierarchy should still make sense even when the user only reads the headings.

### **Show more physical proof**

The current visual language feels closer to a software or technology company. The grids, dots and glowing typography communicate innovation, but LumenX also needs to feel like a company that delivers real lighting projects.

Balance the technology-led style with:

* Actual luminaires  
* Completed environments  
* Project photography  
* Lighting layouts  
* Simulations  
* Installation details  
* Drawings  
* Data sheets  
* Product documentation

### **New design direction**

The recommended direction is:

*A simple, premium website with engineering-level evidence and contractor-level practicality.*

Use the following design discipline throughout:

* One idea per section  
* One clear heading  
* Minimal supporting copy  
* One strong image or technical visual  
* Generous spacing  
* Clear progression  
* Deeper detail on dedicated pages
